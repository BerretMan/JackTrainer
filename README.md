# Jack Trainer 

A web application writen in **Sveltekit** to train on Blackjack. 

You can access the app here https://jack-trainer-kappa.vercel.app/

## Game Modes

- **Play** a 1vs1 against the dealer 
- **Hi-lo Count** Given a blackjack hand, you have to gave the correct Hi-lo Count
- **Hi-lo Speedrun** To train your speed on counting card
- **Best Move** Given a blackjack hand, you have to guess the perfect move
